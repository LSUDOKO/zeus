# zeus

A mobile Bitcoin wallet fit for the gods. ⚡️ Est. 563345

Package manager: yarn.

## Commands

- test: `yarn test`
- lint: `yarn lint`

## Layout

- `android/`
- `assets/`
- `components/`
- `ios/`
- `locales/`
- `utils/`
- `views/`
- `zeus_modules/`

## Rules

- Run `yarn test` before you say a change is done.
- Never commit secrets or `.env` files.
